# Markdown Syntax Guide

## Headers

# H1 Header
## H2 Header
### H3 Header
#### H4 Header
##### H5 Header
###### H6 Header

## Emphasis

*italic text* or _italic text_
**bold text** or __bold text__
***bold and italic***
~~strikethrough~~

## Lists

### Unordered List
- Item 1
- Item 2
  - Nested item 2.1
  - Nested item 2.2
- Item 3

### Ordered List
1. First item
2. Second item
   1. Nested item 2.1
   2. Nested item 2.2
3. Third item

### Task List
- [x] Completed task
- [ ] Incomplete task
- [ ] Another task

## Links and Images

[Link text](https://example.com)
[Link with title](https://example.com "Title")

![Alt text](image.png)
![Image with title](image.png "Image title")

## Code

Inline `code` example.

```javascript
function greet(name) {
    return `Hello, ${name}!`;
}
```

```python
def factorial(n):
    if n <= 1:
        return 1
    return n * factorial(n - 1)
```
